Entry for the make.fun bounty [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea): a single funny line of at most 200 characters, written by `main.ts` to `/output/entry.txt`.

The line:

> I told my alarm clock we need to talk. It said, "Perfect — I'll wake you up at 5 a.m. to discuss it."

Run it with Node 22+:

```sh
node main.ts
```

Fully offline and deterministic: no network calls, no API keys, no model calls at runtime.
